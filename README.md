# DataHack

This repository contains our group project analyzing California's Local Control Funding Formula (LCFF) and its relationship with educational outcomes across school districts.

## Repository Structure

- `data/raw/`: Original downloaded datasets
- `data/cleaned/`: Cleaned datasets used for analysis
- `code/`: Individual folders for each group member's work
- `outputs/`: Final figures, tables, and other project outputs
